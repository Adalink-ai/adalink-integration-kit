MCP da Adaflow

Servidor MCP remoto do Adaflow Connect. Conecte seu cliente MCP em /mcp (Streamable HTTP, só POST).

Credencial: token de app em x-ada-token ou Authorization: Bearer ada_..., ou o JWT do usuário em Authorization: Bearer.

Guia: github.com/Adalink-ai/adalink-integration-kit/connect/mcp
